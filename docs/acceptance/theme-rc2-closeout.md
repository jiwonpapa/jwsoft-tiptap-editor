# 0.1.1-rc.2 테마·본문 서식 개선 배포 기록

## 결과

- 승인된 공유 로컬과 온라인에 `0.1.1-rc.2`를 배포했습니다. 두 곳 모두 JWSoft active / CKEditor inactive입니다.
- 구현 `6215940`, 후보 패키지 `e6c596f`, CI 실행 분리 `61aaea7`을 차수별 커밋했습니다. 공개 태그는 `v0.1.1-rc.2`이며 CI 변경은 패키지·런타임을 바꾸지 않습니다.
- G7 팔레트를 따르는 설정 UI, 두 다크모드 신호, 모바일 경고 배치와 미배포 상태였던 제목·인용·체크리스트·글자색/강조색 수정을 포함합니다. G7 코어와 관리자 템플릿은 수정하지 않았습니다.

## 검증

- 단위 170개, 통합 7개와 상태 동기화 10개, 브라우저 37개 통과. 브라우저 11개는 비대상 viewport skip입니다.
- 별도 헤드리스 Chrome에서 공개/관리자 게시판 이미지 업로드·저장·재편집, 잘못된 이미지와 재시도의 HTTP 422 거부를 확인했습니다.
- MP4 업로드 파일명과 확장자, 편집/조회 원본 비율, 재생 시간 증가, Range HTTP 206을 확인했습니다.
- YouTube·X 주소 자동 삽입과 실패 URL 원문 보존, 상품 한영 빠른 탭 전환 저장, 페이지 신규·수정·조회, 답글 저장을 확인했습니다.
- 빈 본문 HTTP 요청 18개를 서버가 거부했고 기존 본문 해시가 유지됐습니다.
- 1280px·390px의 라이트/다크 설정 UI와 새로고침 유지, 모바일 가로 넘침 없음, 한영 접근성 이름을 확인했습니다. 도움말 대비는 7.56:1 / 9.96:1입니다.
- 실제 GitHub 설치 생명주기를 거쳐 후보 57/57 → 배포 전 60/60 → staging 후 61/61 → production 후 62/62를 통과했습니다.

## 발견 사항과 경계

- 제보된 원래 흰 설정 화면은 전용 G7에서 재현되지 않았습니다. 이번 변경은 테마 연동 보완이며 원인 확정으로 표현하지 않습니다.
- 페이지 자동화 초기 1회에 빈 값이 저장됐습니다. 후속 실제 수정과 새 글 3건에서 요청/응답·재편집을 검증했고 재현되지 않았습니다. 초기 요청이 남지 않아 원인을 확정하거나 에디터 결함을 해결했다고 주장하지 않습니다.
- 최초 CI 2회는 100회 생성·해제 검사에서 10초 시간 초과였습니다. 단독 검사는 2.4초에 통과했고, CI의 DOM 검사 worker를 1개로 분리한 뒤 전체 CI가 통과했습니다. 검사 횟수·assertion·제한 시간은 유지했습니다.
- 실행 가능한 self-hosted 릴리스 러너가 없어 이번 대기 workflow만 취소했습니다. 동일 후보 게이트를 전용 G7에서 실행한 결과와 GitHub CI를 구분합니다.
- 인증된 관리자 설정 화면의 색상 검증은 전용 G7에서 수행했습니다. 운영 사이트는 설치 파일·공개 JS·레이아웃 DB·로그인 화면 검증 범위입니다. 사용자 브라우저는 사용하지 않았습니다.
- 새 안정판 또는 모든 외부 제공자/실기기에서의 완벽 동작을 선언하지 않습니다.
