# 관리자 설정 테마 보완

## 범위

- JWSoft 설정 화면과 해당 화면에서 열린 선택 메뉴에만 G7 색상 토큰을 적용합니다.
- 카드·입력·설명·버튼·경고와 브라우저 기본 입력의 색상 모드를 함께 전환합니다.
- 에디터·모달·문서 표시도 `html.dark`와 `html[data-theme="dark"]`를 지원합니다.
- G7 코어·관리자 템플릿·페이지 빌더·사이트 테마 저장값은 변경하지 않습니다.
- 원래 제보된 흰 화면은 전용 G7에서 재현되지 않았습니다. 설치본 설정 레이아웃과 기존 소스도 같았습니다. 이 변경을 확인되지 않은 원인의 해결로 단정하지 않습니다.

## 확인

- 별도 헤드리스 Chrome, 전용 G7 테스트 런타임에서 인증된 설정 페이지를 사용했습니다. 사용자 브라우저는 사용하지 않았습니다.
- 1280px·390px 각각 밝은 → 다크 → 밝은 모드를 UI로 전환했습니다. 카드 5개와 열린 선택 메뉴가 G7 테마 토큰과 일치했습니다.
- `data-theme` 단독 신호와 새로고침 후 다크 모드 유지도 확인했습니다.
- 설명 글자 대비는 밝은 모드 7.56:1, 다크 모드 9.96:1입니다.
- 모바일 경고는 제목·본문을 세로 배치하여 가로 flex 압축을 제거했습니다. PC·모바일 스크린샷을 직접 확인했습니다.
- 최종 자동 검사: 단위 170개, G7 통합 7개와 상태 동기화 검사 10개, 브라우저 37개 통과. 브라우저 skip 11개는 반대 viewport이며 실제 외부 제공자 검사 2개는 opt-in 실행해 통과했습니다.
- 화면 증거는 로컬 `output/playwright/editor-rc2/`에 보존합니다. 배포 결과는 아래와 [RC2 배포 기록](theme-rc2-closeout.md)을 따릅니다.

## 배포

- `0.1.1-rc.2` 공개 후보와 승인된 공유 로컬·온라인에 동일 ZIP을 적용했습니다. 새 안정판 선언은 아닙니다.
- GitHub 설치·업데이트·데이터 보존 제거·에디터 복귀를 실제 실행했습니다. 후보 57, 배포 전 60, 온라인 staging 후 61, production 후 최종 62개 기준을 순서대로 통과했습니다.
- 양쪽 설치 파일 181개, 공개 JS, 등록된 설정 레이아웃의 테마 적용 클래스가 일치합니다. 기존 콘텐츠·설정·모듈·타 플러그인 상태를 보존했습니다.
- 운영 사이트의 로그인 화면과 HTTP 응답은 직접 확인했습니다. 인증된 관리자 설정의 라이트·다크 전환 검증은 전용 G7에서 했으며, 운영 관리자 로그인 검증으로 표현하지 않습니다.
