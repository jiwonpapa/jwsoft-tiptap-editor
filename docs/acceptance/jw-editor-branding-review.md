# jw-editor 명칭·도움말·소개 이미지 검증 상태

2026-09-02의 작업 기록입니다. 정식 출시·운영 배포 완료 보고가 아닙니다.

## 구현

- 사용자 표시 이름 `jw-editor`, 하단 왼쪽 버전과 도움말 버튼, 한영 도움말 모달.
- 현재 편집 내용의 정제된 HTML을 읽기 전용으로 조회·복사. 원문 HTML 편집 기능이 아닙니다.
- 기본 편집·이미지·표·미디어·SNS 내부 확장 조립 구조. 외부 모듈을 런타임 설치하는 SDK는 아닙니다.
- Apache-2.0, NOTICE, 제3자 고지, 패키지 라이선스 일치 검사.
- README 소개·설치·범위·개발 문서. 인트로는 편집 문서가 중심이며 회사 캐릭터는 문서 내부의 작은 선택 이미지로 배치했습니다. `지원` 한글은 제거했습니다.
- 플러그인 식별자·저장소 주소·네임스페이스·DB·canonical HTML 정책은 유지합니다.

## 확인한 결과

- `make check`: unit 179건 및 PHP·정적·보안 검사를 통과했습니다.
- 전용 G7 체크아웃의 `make integration-check`: 7개 suite와 상태 동기화 10개 시나리오를 통과했습니다.
- `make license-evidence`: 재현 빌드와 Apache/NOTICE·npm 49개·Composer 7개 의존성 고지를 확인했습니다.
- Chromium E2E: 39건 통과, 반대 viewport 조건의 11건 skip. 실제 외부 SNS 검사를 포함한 실행입니다.
- 독립 헤드리스 Chrome의 로그인한 G7 화면에서 도움말을 데스크톱/모바일 × 밝은/다크 4조건으로 확인했습니다. 모달 넘침 없음, 읽기 전용 소스, Escape 포커스 복귀, 본문 무변경을 확인했습니다.
- 공개·관리자 게시판에서 실제 이미지 업로드 → 저장 → 재편집을 확인했습니다. 잘못된 이미지와 재시도는 모두 HTTP 422였습니다.
- 별도 QA 게시글에 빈 본문 HTTP 검사 18건을 실행했고 기존 게시글 본문 해시가 유지됐습니다.
- 초기 페이지 입력 후 즉시 저장·서식 지정 직후 저장·대기 후 저장을 각각 2회 검사한 6건에서 요청·응답·재편집 본문이 일치했습니다.

## 아직 완료하지 않은 것

- 과거 초기 페이지의 본문 NULL 관찰 원인은 미확정입니다. 이번 6건이 통과했다고 과거 결함을 수정한 것으로 표현하지 않습니다.
- MP4 재검사 중 업로드 탭 선택 누락과 viewport 전환 직후 측정 문제가 테스트 도구에서 발생했습니다. 이후 모바일의 실제 영상 크기 180×320, 표시 310×551을 관찰했으나 전체 기능 감사는 다시 완료해야 합니다.
- 현재 버전에 맞는 상품·답변·페이지 공개 화면·fallback 및 수명주기 증거 갱신이 남았습니다. 이전 버전 증거의 checksum이나 버전을 바꿔 재사용하지 않습니다.
- 이 시점 후보 gate는 45/57입니다. GitHub 수명주기·staging·production을 포함한 최종 62개 gate는 미완료입니다.
- 코드와 소개 이미지는 로컬 커밋했습니다. 새 버전 GitHub 공개·g7pb·온라인 운영 배포·stable 태그는 하지 않았습니다.

이미지와 도움말을 완성한 것, 자동 테스트를 통과한 것, 실제 기능 감사를 마친 것, 운영에 배포한 것은 별도 상태입니다.
