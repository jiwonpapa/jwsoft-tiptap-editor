# alpha.20 UI·UX 검증 범위

## 구현

- 1차 `9976874`: Lucide 아이콘 툴바, 반응형 더보기, 본문을 밀지 않는 모달, 이미지 파일/주소 탭과 다중 업로드 큐.
- 2차 `37fd232`: 정책 1.5.0 글자 서식, 문맥 도구, 표 병합/분할·셀 속성, 이미지 너비 조절, 체크리스트·찾기/바꾸기·전체화면·문자 수.
- G7 FileUploader는 공개 React/component registry를 통한 선택 UI 재사용이며, 저장은 JWSoft API를 유지합니다. G7 일반 첨부 API나 코어 파일을 변경하지 않습니다.

## 확인한 증거

- 단위 검사 85개: 범위별 글자 서식, 허용 토큰 왕복, 체크리스트·이미지 UI 요소의 정본 제외, 셀 선택 병합/분할, 유니코드 찾기, 수명주기와 업로더 계약.
- Chromium 데스크톱/모바일 17개 시나리오: 모달 본문 위치 보존, 화면 가로 넘침 없음, 실제 IME composition·Clipboard API, 찾기/바꾸기 실행취소, 표/이미지 조작, 모달 취소 후 늦은 카드 삽입 방지. 반대 뷰포트 전용 11개 실행은 의도적으로 제외합니다.
- `make check`, `make build`, 전용 G7 7.0.9의 `make integration-check`: 저장 미들웨어, 설정, 권한, 이미지, MP4 청크, SSRF 방어 검사.
- 전용 G7의 alpha.19 → alpha.20 ZIP 업데이트, CKEditor 충돌 차단·롤백·JWSoft 복귀와 기존 검증 문서 해시 보존.
- 두 번의 재현 패키지 checksum 일치, 자체 포함 NPM 49개·Composer 7개 라이선스 검사.

## 증거의 경계

브라우저 시나리오는 G7 adapter를 구동하는 격리 페이지와 mock 업로드/미리보기 API를 사용합니다. 실제 G7 인증 화면의 FileUploader 선택·전송과 모바일 실기기 가상 키보드 관찰을 대신하지 않습니다. 이번 작업 중 인증 브라우저 로그인이 승인되지 않아 실제 G7 업로더의 시각·실사용 확인은 보류했습니다.

기존 전 화면 생성/재편집 parity 자료의 관찰 버전은 별도 provenance를 그대로 유지합니다. 이번 빌드로 다시 관찰한 것으로 바꾸지 않습니다. 기술 검사 통과 개수를 제품 완성도나 stable 승인으로 표현하지 않습니다. 이 버전은 개발·승인된 staging용 alpha이며 production 동일 산출물 게이트를 충족한 stable 릴리스가 아닙니다.
