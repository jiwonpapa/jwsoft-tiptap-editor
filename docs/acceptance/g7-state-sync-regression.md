## 증거 경계

DOM 통합 검사는 인증·HTTP 저장·DB 쓰기를 하지 않으며, 독립 UI 검사는 G7 상태 API를 대체한 테스트 환경입니다. 실제 저장·재조회와 이미지 전용 글은 위 승인 후 검증으로 별도 확인했습니다. 인앱 브라우저는 `Input.imeSetComposition`을 지원하지 않아 실제 G7 재렌더 중 IME 조합 이벤트나 Android/iOS 키보드를 이번 실행에서 관찰한 것으로 주장하지 않습니다. 앞선 사용자 실기기 확인 역시 이번 소스 변경 이후의 재검증 결과로 재사용하지 않습니다. 한글 조합 이벤트 회귀의 현재 증거는 별도 Chromium 자동 검사입니다.

앞선 인증 권한 대기 상태는 제품 소유자의 승인으로 해제한 뒤 정규 로그인 및 화면 저장 동작으로 검증했습니다. 전용 QA 계정은 검증 종료 후 권한·토큰을 회수합니다. RC 공개·staging·production 배포 및 62/62 최종 상태는 후속 배포 증거로 판단합니다.

기존 실패 기록은 [RC1 로컬 검증](g7-rc1-local-validation.md)에 그대로 보존합니다. 새 검사 통과를 과거 실패 기록의 통과 전환으로 사용하지 않습니다.
