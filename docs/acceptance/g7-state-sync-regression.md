# G7 제출용 본문 동기화 보완 — 2026-08-31

## 구현 및 확인 결과

- 본문 동기화의 300ms debounce는 유지하고 공개 `state.setLocal`의 `render:true`로 제출용 폼 스냅샷도 갱신합니다. G7 코어·번들 템플릿·게시판 모듈은 변경하지 않았습니다.
- 현재 에디터 소스와 실제 G7 실행 번들·기본 게시판 저장 시퀀스를 함께 사용하는 DOM 통합 검사를 추가했습니다. 수정 전에는 너비 변경 뒤 제출 본문이 빈 문자열이어서 실패했고, 수정 후에는 아래 5개가 통과했습니다.
  - 신규 글의 일반 저장
  - 신규 글의 화면 너비 변경 후 저장
  - 수정 글의 화면 너비 변경 후 저장
  - 입력 직후 저장 시 debounce 반영
  - 다국어 본문 저장 및 다른 언어 보존
- 에디터를 G7이 렌더링하는 DOM 안에 배치해 선택 위치·DOM 연결·에디터 instance가 유지되는지도 확인했습니다.
- 전용 G7 통합 검사에 포함하여 소스 checksum으로 검증 증거를 연결했습니다.

## 아직 증명하지 않은 범위

이 결과는 인증·HTTP 저장·DB 쓰기 없는 DOM 통합 검사입니다. 실제 사이트의 저장·재조회, 전체 폼 재렌더 성능, 한글 조합 입력 및 이미지 전용 글의 최종 회귀를 대신하지 않습니다. 앞선 사용자 실기기 확인 역시 이번 소스 변경 이후의 재검증 결과로 재사용하지 않습니다.

인증된 실제 화면 검증은 로그인 권한 확인으로 중단했으며, 다른 계정·API 경로로 우회하지 않았습니다. 현재 소스 변경으로 이전 실행 번들·패키지 기반 증거는 다시 생성해야 합니다. 따라서 RC 공개·staging·production 배포 및 62/62 승인은 여전히 미완료입니다.

기존 실패 기록은 [RC1 로컬 검증](g7-rc1-local-validation.md)에 그대로 보존합니다. 새 검사 통과를 과거 실패 기록의 통과 전환으로 사용하지 않습니다.
