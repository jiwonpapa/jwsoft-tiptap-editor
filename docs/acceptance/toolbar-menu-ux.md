# 툴바 더보기 UX 개선 검증

검증일: 2026-08-30. 최초 구현은 `alpha.20` 이후이며, `v0.1.0-alpha.21`로 공개하고 승인된 staging에 배포했습니다. 아래 화면 검사는 독립 Chromium UI 증거이며, 인증된 G7 화면의 최신 재검증이나 production 배포 증거는 아닙니다. 패키지·배포 결과는 [배포 검증 기록](../09-deployment.md)을 따릅니다.

## 구현

- 1차 `d722cea`: 글자 모양·목록·문단 모양을 분리하고 더보기에는 찾기/바꾸기·전체화면만 유지. 메뉴의 기능명/선택 표시와 표 편집의 문맥 도구 단일화.
- 2차 `083a1cf`: 실측 폭 기반 삽입 그룹 접힘, 기록 도구 상시 노출, 모바일 native 하단 시트, 선택 영역 매핑, 키보드 이동/복귀와 모달 중첩 방지.
- G7 코어·서버 저장 정책·DB 구조·업로드 계약·공개 설정은 변경하지 않았습니다. 기존 저장 본문을 일괄 변환하지 않습니다.

UI 회귀에는 다음을 포함합니다.

- 360/390/768/1280px 왕복 리사이즈에서 가로 넘침 없음, 실행취소/다시실행 노출 유지.
- 좁은 데스크톱 내장 에디터도 컨테이너 폭에 따라 삽입 그룹을 접음.
- 더보기 명령 2개, 목록 3개, 선택한 목록 표시와 본문 복귀.
- ArrowDown으로 메뉴 진입, 위/아래/Home/End 이동, Escape 호출 버튼 복귀.
- 모바일 모달의 Tab 순환, 정렬/간격/크기 연속 적용과 선택 텍스트 보존.
- 입력 모달 전환 시 열린 native modal 1개, 취소 후 숨겨진 내부 항목 대신 툴바 버튼 복귀.
- 한글 IME·붙여넣기·실행취소, 이미지/영상/스마트카드, 표/이미지 문맥 도구와 100회 화면 수명주기 회귀.
- 정본에 UI 버튼/체크박스/임의 style/data 속성을 저장하지 않음.

스크린샷은 `test-results/playwright/`의 `editor-more-menu.png`, `editor-list-menu.png`, `editor-text-sheet.png`, `editor-paragraph-sheet.png`, `toolbar-360.png` 등에 생성됩니다. 애니메이션은 캡처 때 완료시켜 중간 투명 프레임을 증거로 남기지 않습니다.

## 증거 범위와 미수행

- UI 브라우저 검증은 G7 어댑터 fixture와 로컬 미리보기입니다. 운영 사이트의 로그인된 작성 화면 검증과 구분합니다.
- 실제 휴대전화의 가상 키보드, Safari/Firefox 실기기, 운영 테마별 화면 승인은 수행하지 않았습니다.
- 이번 변경에 대한 버전 증가·ZIP 패키징·GitHub 릴리스·원격 배포는 수행하지 않았습니다. 기존 stable parity의 미완료 배포 조건을 통과 처리하지 않습니다.
- 로컬 UI 확인은 `harness/ui-preview.html`로 반복할 수 있습니다. 서버 저장/파일 업로드 없는 작성 도구 전용 미리보기입니다.
