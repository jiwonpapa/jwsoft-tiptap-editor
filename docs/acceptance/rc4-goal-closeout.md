# RC4 Enter·외부 삽입 개선 진행 기록

목표: 제목 Enter 방어, X·Facebook 공식 화이트리스트 표시, 기존 미디어 편집/조회 동등성을 통합하고 현재 패키지 검증 후 두 승인 대상에 배포.

## 1차

- 커밋 `054d6a2`: 미처리 기본 GET 제출만 방어. G7 코어·번들 무수정.
- 단위 7건 및 실제 Chromium 데스크톱/모바일 제목 Enter 2건 통과.
- 제목 보존, 본문 필수 오류, 본문 포커스, 저장 버튼 Enter 동작 확인.
- 실제 로그인 G7 재검증은 아래 후속 차수에서 기록한다.

## 2차

- 정책 1.6.0 및 ADR-0014: 고정 X·Facebook URL/SDK/CSP 화이트리스트, 제공자별 토글.
- 편집/조회 동일 공식 표시기. canonical HTML에는 SDK/iframe/실행 DOM을 저장하지 않음.
- 공식 SDK의 opaque-origin sandbox 실험은 X CORS/Facebook 제약으로 실패하여 채택하지 않음. 현재 표시 프레임은 보안 sandbox가 아니며 외부 SDK 신뢰 위험을 명시.
- 모바일 삭제 검사에서 포커스 전환과 문서 변경을 한 chain에 넣으면 삭제되지 않는 경로를 발견. 문서 변경 후 포커스로 순서를 분리하고 3회 연속 통과. 영상 노드에도 동일하게 적용.
- `make check` 163개 단위 및 PHP/공급망/배포 계약 통과, 독립 Chromium 29개 통과·13개 비대상/실제 제공자 opt-in 제외.
- 실제 X 공식 게시물의 본문·사진, Facebook 공개 게시물의 본문·사진 표시 확인. 데스크톱/모바일 두 실행 통과. 조회·편집은 각각 화면 증거로 구분.
- 처음 사용한 Facebook 예제는 이용 불가 응답으로 실패했고 성공 증거에서 제외. 공개 게시물로 교체해 재검증했으며 오류 판정 기준은 유지.
- G7 설정·서버 whitelist descriptor·기존 SSRF 통합검사 통과. ZIP 설치/로그인 화면/배포 증거는 아직 별도 단계.

## 패키지·실제 G7·배포

진행 중. 이전 RC3 배포나 RC4 개발 overlay 검증을 이번 후보 배포 증거로 재사용하지 않는다.
