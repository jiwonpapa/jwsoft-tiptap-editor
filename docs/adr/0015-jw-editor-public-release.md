# ADR-0015: jw-editor 명칭과 Apache-2.0 공개 배포

- 상태: 승인 — 2026-09-02 제품 소유자의 명칭·도움말·공개 배포·Apache 라이선스 요청
- 대체: ADR-0006의 제품 라이선스, ADR-0010의 Proprietary/UNLICENSED 조건

## 결정

공식 제품명은 `jw-editor`, 제품 라이선스는 Apache-2.0입니다. npm 패키지는 GitHub/G7 배포와 별개이므로 `private: true`를 유지하되 라이선스는 Apache-2.0으로 표기합니다. 의존성의 이름·저작권·라이선스 원문은 보존합니다.

기존 설치를 다른 플러그인으로 오인하지 않도록 `jwsoft-tiptap-editor` 식별자, 저장소 URL, PHP 네임스페이스, DB 테이블, 저장 토큰, 전역 런타임 이름을 유지합니다. 사용자에게 보이는 이름만 변경합니다. 데이터 마이그레이션은 없습니다.

## UI와 범위

- 시각 방향: 기존 에디터의 차분한 표면과 강조색을 유지하고, 하단 왼쪽에 제품명·실제 패키지 버전·도움말 버튼을 배치합니다.
- 콘텐츠: README 인트로 이미지 → 제품 소개/기능 → 설치/전환 → 지원 범위/개발 안내 순서입니다.
- 상호작용: 기존 모달 열림 효과와 버튼 hover/focus를 재사용하며 reduced-motion을 존중합니다. 도움말은 Escape·닫기·포커스 복귀를 지원합니다.
- 소스보기는 읽기 전용 HTML 조회·복사입니다. 원문 HTML 편집, 임의 style/class/script 저장을 허용하지 않습니다.
- 내부 schema 확장을 기본 편집·이미지·표·미디어·SNS 모듈로 조립합니다. 공개 동적 모듈 로더, 제3자 코드 실행, 플러그인 마켓은 도입하지 않습니다.

## 보안·호환성과 출시

Apache-2.0은 제품 소유자의 코드 배포 조건을 변경하며 제3자 라이선스를 재작성하지 않습니다. 라이선스/NOTICE/의존성 고지를 패키지에 포함하고 일치 검사를 유지합니다. 저장 정책·권한·서버 검증은 변경하지 않습니다.

페이지 초기 저장 누락 관찰은 별도로 원인을 확인해야 합니다. UI·브랜딩 완료나 기존 버전의 통과 기록으로 이를 종결하지 않습니다. 정식 버전은 새 입력과 동일 패키지로 57/60/61/62 게이트를 다시 통과한 뒤에만 공개합니다.
