# ADR-0016: Python 주 하네스와 강제 가능한 개발 규약

- 상태: 승인 — 2026-09-02 제품 소유자가 헌법·인프라·하네스 개선 및 Python 주언어/Shell 단순 배포를 명시
- 규약 버전: 2; 플러그인 버전 변경/배포 승인은 별개

## 결정

검사·증거·출시 판단은 `harness/jw_harness/`의 Python으로 통합합니다. Shell은 간단한 명령 연결, TypeScript는 제품과 브라우저 테스트, PHP는 서버 및 Laravel 연동 검사에 사용합니다. JS 빌드/AST/생성기는 해당 언어 도구로 유지하되 범용 Node 하네스를 더 추가하지 않습니다.

기존 Node 검증기 및 대형 함수는 파일별 이전 목록, 담당, 만료일, 증가 금지 상한을 둡니다. 전체를 즉시 재작성하여 회귀를 만들거나, 목록으로 제외한 뒤 완료를 주장하지 않습니다. 새 Python 모듈은 파일 300줄/함수 80줄/복잡도 10, Ruff·mypy strict를 적용합니다.

정식 자동 게시의 후보 57개 우회 경로를 제거합니다. Python 정식 게시 명령은 실제 final gate를 다시 실행한 후 62개와 두 배포 ZIP 일치를 확인하며 재빌드하지 않습니다. 기존 수동 관측→pass 기록기 3개는 실패 종료하는 폐기 진입점으로 바꾸고 관측값은 Python에서 `unverified`로만 기록합니다.

## 영향 및 제외 범위

- G7 코어·DB·저장 정본·관리자 공개 설정·허용 HTML은 변경하지 않습니다. shared G7/운영 배포는 이 작업 범위가 아닙니다.
- 인증 헤더 중복은 기존 동작을 유지하는 G7 어댑터로 모읍니다. 정적 검사가 발견한 Promise 처리와 타입 표기는 수정하고 회귀 검사합니다.
- 1,700줄 UI suite는 공통 fixture와 5개 영역으로 나누며 테스트 이름/검증을 보존합니다.
- PHPStan 초기 범위는 독립 실행 가능한 sanitizer/content/social policy/값 객체/예외입니다. G7/Laravel 심볼이 필요한 서비스·컨트롤러 전체의 정적 분석 완료는 아닙니다.
- 기존 수동 G7 화면 증거를 자동 실행 증거로 바꿔 적지 않습니다. 추적되는 G7 실제 실행 하네스로 이전하기 전 해당 경로의 새 자동 증명은 미완료입니다.
- 커버리지는 측정된 기준에 근거한 최소 하한이며 제품 기능 완성률이 아닙니다.

## 보안·호환성·마이그레이션

Python은 개발/CI 환경에만 필요하며 설치 ZIP의 런타임 의존성을 늘리지 않습니다. Python 도구는 전용 venv와 정확한 버전 목록을 사용합니다. 파일 접근은 저장소 경계, 정리는 캐시 allowlist를 확인합니다. 프로덕션 SSH 및 플러그인 변경은 기존 명시 승인 절차를 유지합니다.

하네스·CI·규약도 fingerprint 입력이므로 과거 pass 증거가 무효화되는 것은 의도된 변경입니다. `.build`의 기존 파일은 지우지 않으며 더 이상 정식 소스로 사용하지 않습니다. 만료일은 임의 연장하지 않고 추가 승인/ADR과 실제 분리 결과를 요구합니다.

## 검증

`make check`, `make build`, `make audit`, `make browser-check`와 Python 금지 사례 회귀를 사용합니다. 브라우저 명령은 독립 headless 환경을 사용하며 운영 로그인·DB 저장의 증거로 표현하지 않습니다. 정식 게시/삭제의 위험 동작은 임시 fixture·mock로만 검증합니다.
