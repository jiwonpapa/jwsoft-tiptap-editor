# ADR-0019: 번들 이미지 편집 하위 모듈

- 상태: Accepted (2026-09-08 형님 승인: jw-editor 내부 선택형 모듈)
- 적용 버전: Unreleased
- 관련 결정: 헌법 제3조·제4조·제6조·제14조

## 결정

이미지 편집은 별도 G7 플러그인이 아니라 `jw-editor`에 포함된 선택형 하위 모듈로
제공한다. 관리자 `imageEditor` 설정은 기본 OFF이며, 이미지 업로드가 허용된 편집
화면에서만 활성화한다. 향후 AI 글쓰기 같은 선택 기능도 같은 내부 기능 계약을
따르되, 이번 결정은 이미지 편집만 구현한다.

편집 UI는 MIT `filerobot-image-editor@5.0.0`과
`react-filerobot-image-editor@4.9.1`을 고정 버전으로 자체 번들한다. npm의 beta 태그나
외부 CDN을 사용하지 않는다. 큰 편집 번들은 기능을 실제 열 때만 플러그인 자산
경로에서 로드한다.

## 데이터와 보안 경계

- 편집 대상은 플러그인의 인증된 업로드 API가 관리하는 JPEG·PNG·WebP 이미지로
  제한한다. 외부 URL, GIF, AVIF는 첫 버전에서 편집하지 않는다.
- 브라우저 결과를 신뢰하지 않는다. 편집 결과는 기존 이미지 업로드 API로 다시
  전송하고 서버가 MIME·용량·픽셀·권한을 재검증한다.
- 원본 파일과 업로드 기록을 덮어쓰거나 삭제하지 않는다. 새 업로드 URL만 현재
  이미지 노드의 `src`에 적용하고 alt·title·caption·정렬·크기 토큰은 보존한다.
- 캔버스·편집기 내부 상태·임의 style/class/data 속성은 canonical HTML에 저장하지
  않는다. 저장 HTML 정책과 G7 코어는 변경하지 않는다.
- 닫기·취소·실패·업로드 취소 시 원문과 선택 이미지를 유지한다.

## 모듈 계약

내부 기능 레지스트리는 식별자, 설정 키, 활성 조건과 설치 함수를 명시한다. 설정 OFF
상태에서는 편집 버튼과 대형 자산 요청이 없어야 한다. 외부 패키지가 런타임에 임의
코드를 등록하거나 URL에서 확장을 내려받는 공개 플러그인 SDK는 제공하지 않는다.

## 공급망과 라이선스

Filerobot과 대부분의 전이 의존성은 MIT이다. `hoist-non-react-statics`의 BSD-3-Clause와
`caniuse-lite` 데이터의 CC-BY-4.0은 고지·원문 포함을 조건으로 허용한다. lockfile,
advisory, 라이선스 원문, NOTICE와 재현 패키지 검사를 통과하지 못하면 출시하지 않는다.

## 검증

- 설정 OFF/ON, 업로드 OFF 종속성, 읽기 전용과 다국어 인스턴스
- 관리 이미지 판별, 외부 URL·GIF·AVIF 거부, 취소와 오류 원문 보존
- crop/rotate/resize/adjust 결과를 새 파일로 업로드하고 선택 이미지의 `src`만 교체
- 서버 재검증 실패, 네트워크 중단, 모달 재진입과 editor destroy 정리
- 데스크톱·모바일·다크 테마, 키보드 focus, 가로 넘침, 지연 로드
- lockfile advisory·라이선스·번들·패키지 자산 포함
