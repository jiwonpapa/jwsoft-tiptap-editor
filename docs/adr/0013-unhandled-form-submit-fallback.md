# ADR-0013: 에디터 연결 폼의 미처리 기본 제출 방어

- 상태: Accepted
- 승인: 2026-08-31 목표 추진 지시
- 범위: 플러그인 런타임. G7 코어·번들·저장 API 변경 없음.

## 근거

로그인 상태의 공개/관리자 작성 폼에서 제목 Enter는 저장 버튼의 click 액션을
실행하지 않고 기본 GET 제출을 일으켰다. 제목은 URL 쿼리로 이동하고 초기화됐다.
등록 버튼은 기존 서버 필수 검증을 통과하지 못하고 422를 반환했다.
즉 이 재현은 빈 본문의 서버 저장 성공이 아니다.

## 결정

에디터가 속한 form에 한정하여 window bubble 단계에서 처리되지 않은 submit을
방어한다. submitter가 없고, 명시적 action이 없고, 기본 GET인 경우만 차단한다.
프레임워크가 이미 preventDefault한 제출, POST, submit 버튼, 다른 폼은 건드리지 않는다.

- 빈 본문: 제목/화면을 유지하고 본문 필수 오류와 편집 포커스를 제공한다.
- 본문 있음: 편집 포커스로 이동하고 기존 등록 버튼 사용을 안내한다.
- IME 조합 중: 이동은 막되 조합 포커스는 빼앗지 않는다.
- 서식 손실 확인 전 읽기 전용: 편집을 해제하지 않고 확인을 안내한다.
- 에디터 파괴·재초기화·언어 전환 시 리스너를 제거한다.

저장 버튼 탐색/대리 클릭, 전역 Enter 가로채기, 호스트 폼 속성 변경은 하지 않는다.
이 방어는 저장 구현이 아니며 서버 canonical HTML 정제와 필수 검증을 대체하지 않는다.
G7에 공식 공통 submit 계약이 생기면 이를 우선하고 이 fallback은 제거 가능하다.

## 검증

단위검사로 적용/비적용 경계, IME, 읽기 전용과 해제를 확인한다.
브라우저에서 실제 제목 Enter의 URL·제목 보존, 필수 오류, 포커스와 등록 버튼 Enter를
검사한다. 공개/관리자 로그인 G7 검증과 서버 422 검증은 별도 증거로 유지한다.
