# ADR-0011: 활성화 선행 설정 제거와 문서별 전환 안내

- 상태: 승인
- 날짜: 2026-08-30

## 배경

G7 7.0.9 관리자는 비활성 플러그인의 설정 버튼을 비활성화합니다. 활성화 전에 `legacyContentRiskAcknowledged`를 요구하면 설정에 들어갈 수 없어 최초 활성화가 불가능합니다. 플러그인의 설정 페이지 경로도 명시적으로 등록해야 합니다.

## 결정

- 사이트 전체 확인 스위치·활성화 차단을 제거합니다. 이전 저장 키는 삭제하지 않고 무시합니다.
- 플러그인 소유 설정 경로를 인증·`core.plugins.update` 권한으로 등록합니다. 고정 경로에는 `route.identifier`가 없으므로 설정 API 식별자를 명시합니다.
- 설치·활성화·조회만으로 저장된 기존 본문은 바뀌지 않습니다. 기존 글을 JWSoft에서 수정 후 저장할 때 지원하지 않는 서식이 달라질 수 있음을 설명·설정·편집 경고에 명시합니다.
- 빈 새 글·호환 HTML·읽기 전용에는 전환 확인을 요구하지 않습니다. 기존 문서의 손실 감지·확인 전 편집/저장 차단, 붙여넣기 안내, 서버 sanitizer는 유지합니다.
- CKEditor와 JWSoft 동시 활성화는 양방향으로 차단합니다. 관리자 오류는 현재 에디터·플러그인 목록 위치·비활성화 후 재시도·복귀 절차를 안내합니다. 관리자 요청에서 기존 에디터를 묵시적으로 끄지 않습니다.
- 비활성 플러그인에서 실행할 수 있는 사용자 정의 전환 모달 계약이 없는 G7에서 코어·기본 템플릿을 수정하거나 강제 의존성 활성화 모달을 오용하지 않습니다. 명시적으로 승인된 배포 하네스의 전환/실패 복귀 절차는 유지합니다.

## 검증

선행 설정 없는 활성화와 양방향 충돌, 설정 경로·GET/PUT·권한, 경고 범위, 새 글·읽기 전용 무경고, 원문 state 무변경 및 문서별 확인 유지, 배포 전환 실패 시 CKEditor 복귀를 회귀 검사합니다. 패키지·실제 설치·브라우저 결과는 별도 기록합니다.
