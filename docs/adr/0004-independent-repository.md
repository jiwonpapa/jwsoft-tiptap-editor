# ADR-0004: 독립 저장소와 G7 테스트 호스트

- 상태: 승인
- 날짜: 2026-08-28

## 결정

제품 SSoT는 `jiwonpapa/jwsoft-tiptap-editor`이며 G7 저장소는 통합 테스트 호스트입니다.

## 이유

플러그인의 버전, 의존성, 보안 릴리스, 라이선스와 배포 수명주기가 G7 코어와 독립적입니다. G7은 GitHub 우선 확장 업데이트와 ZIP 업데이트를 지원합니다.

## 결과

G7 번들 편입이 필요하면 릴리스 산출물에서 동기화하며, 제품 원본을 G7 내부에서 직접 개발하지 않습니다.
