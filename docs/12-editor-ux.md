# 에디터 UX 제품 기준

## 구성 원칙

본문이 중심이며 도구는 일관된 로컬 Lucide SVG와 한국어/영어 접근성 이름을 사용합니다. 보조 서식은 더보기 메뉴로 정리하고 모바일에서는 키보드·본문 공간을 우선합니다. 기본 정책 적용 같은 기술 문구는 상시 노출하지 않습니다.

이미지·영상 등 복잡한 입력은 본문을 밀지 않는 모달, 짧은 선택은 팝오버, 표·이미지 편집은 선택 대상별 도구로 처리합니다. 모달 열림/닫힘, 메뉴 등장, 버튼 상태 변경만 짧게 전환하며 reduced-motion을 존중합니다.

## 이미지 업로드

- 파일 선택과 URL 입력을 탭으로 분리하고 대체텍스트·캡션·배치를 상세 설정으로 묶습니다.
- G7 공개 `window.React`, `window.ReactDOM`, `G7Core.getComponentMap()`에 등록된 `FileUploader`를 선택 전용(`autoUpload=false`)으로 연결합니다. 호스트 소스를 import하거나 React를 중복 번들하지 않습니다.
- 선택 파일은 기존 JWSoft 업로드 API와 서버 검증을 통과합니다. G7 일반 첨부 API로 저장 경로·권한·정리 정책을 우회하지 않습니다.
- G7 컴포넌트가 없는 템플릿에는 로컬 드롭존을 제공합니다. 업로드 큐는 최대 10장의 미리보기·파일별 진행률·오류·재시도·선택 해제를 제공합니다.
- 선택 해제/모달 취소는 진행 중 전송을 중단하고 본문 삽입을 취소합니다. 이미 서버에 완료된 미참조 파일을 자동 삭제하지 않으며 기존 opt-in 정리 정책이 적용됩니다.
- 이미지 상세 설정은 해당 삽입 묶음에 적용합니다. 기존 이미지 교체는 한 장만 허용합니다.

## 작성 도구와 저장 계약

- 글자 모양 메뉴: 선택 범위 12/14/16/18/20/24/28/32px, 글자색 6종, 강조색 5종. 정책 1.5.0의 `span[class]` 토큰으로 저장하며 임의 색상·inline style은 허용하지 않습니다.
- 선택한 텍스트, 표, 이미지에 따라 문맥 도구를 표시합니다. 표는 행·열 추가/삭제, 병합/분할, 머리글 행, 셀 배경·세로 정렬·테두리를 지원합니다.
- 이미지 크기는 마우스/터치 드래그 또는 포커스한 조절점의 방향키로 10~100%를 5% 단위로 변경합니다. 조절점과 드래그 중 화면 스타일은 정본에 저장하지 않습니다.
- 체크리스트, 위/아래 첨자, 서식 지우기, 문자 수, 전체화면, 리터럴 찾기·바꾸기를 제공합니다. 모두 바꾸기는 한 번의 실행취소로 복구합니다.
- 최소 툴바에도 밑줄·이미지 삽입을 유지합니다. 나머지 보조 기능은 더보기로 분리합니다.
- MP4는 URL/파일 입력을 분리하고 파일 드롭·청크 진행 상태를 제공합니다. 영상·링크 카드 모달 취소는 요청을 중단하고 늦은 본문 삽입을 방지합니다.
- 체크박스·이미지 조절점은 편집 UI에만 존재하며 canonical HTML에는 허용된 태그와 토큰만 저장합니다.

## 완료 증거

단위 테스트는 명령·수명주기·G7 브리지 계약을 확인합니다. jsdom 모달 shim은 브라우저 접근성 증거가 아닙니다. 브라우저 테스트에서 실제 모달·배경 비활성화·포커스 복귀·본문 위치 보존·작은 화면 넘침을 별도로 확인해야 합니다.

기존 parity 체크 개수를 제품 완성도 비율로 표현하지 않습니다. 기술 게이트와 시각/실사용 승인은 별개입니다. 한글 IME, 이미지 업로드 실패 복구, 표 수정, 모바일 키보드 상태와 재편집 저장 결과를 함께 확인합니다.

## 범위

G7 코어와 번들 템플릿 수정, 임의 HTML/style/class 허용, 기존 콘텐츠 자동 변환, AI·협업·유료 Pro 도입은 포함하지 않습니다.
