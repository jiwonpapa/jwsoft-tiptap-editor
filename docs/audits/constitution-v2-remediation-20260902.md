## 공개 절차와 남은 승인

현재 헌법 제17조는 후보를 prerelease로만 공개하도록 제한하지만 G7 공식 GitHub 주소 설치/업데이트는 `releases/latest`를 조회합니다. GitHub는 prerelease를 Latest에 포함하지 않으므로 새 후보의 실제 GitHub 수명주기 3개가 실행될 수 없습니다. ADR-0012의 후보 Latest 공개 순서와 ADR-0016의 prerelease 제한이 충돌합니다.

해결 제안은 [ADR-0017 초안](../adr/0017-candidate-latest-channel.md)에 기록했습니다. 명시 승인 전에는 헌법·릴리스 제어를 바꾸거나 새 후보를 Latest로 공개하지 않습니다. 57개 통과를 60/61/62개 또는 운영 배포 완료로 표현하지 않습니다.

기존 대형 함수/Node 검증기의 승인된 이전 부채와 PHPStan 미적용 G7 의존 영역은 원래 범위로 유지합니다. 12개 결함 수정이 모든 기술 부채의 해소나 모든 외부 SNS URL·실기기 검증을 뜻하지 않습니다. 후속 커밋의 최종 판정은 현재 HEAD와 실제 증거를 다시 검사하는 gate 결과를 따릅니다.
